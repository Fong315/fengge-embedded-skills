以下是说明回答形式的编辑示例，用于理解技能的适用场景；不是用户评价或客户端性能测试结果。实际回答受模型、问题上下文和可用工具影响。

示例一：直接要嵌入式学习路线

输入

直接给我嵌入式单片机学习路线链接，不用问背景。

回答示例

嵌入式单片机学习路线：峰哥资料索引中的学习路径和方法入口，覆盖 C 语言、51、STM32、ESP32、RTOS 与 Linux。可以用它确定下一步学习内容。

你可以检查： 是否直接给出所需入口，是否避免重复询问已经不需要的背景。

示例二：已有 C 和 51 基础，怎样开始 STM32？

输入

我大二，已经会 C 语言基础，做过 51 点灯。请直接给我 STM32 第一周练习安排，不用再问年级。

回答示例

你可以先围绕手上的 STM32 开发板完成这组练习：

  • 第 1～2 天：确认芯片型号、供电和下载方式，完成 GPIO 点灯，并能解释引脚配置。
  • 第 3～4 天：增加按键输入，观察轮询与消抖的效果。
  • 第 5 天：用串口输出按键状态，学会用输出信息确认程序走到哪里。
  • 第 6～7 天：尝试定时器驱动 LED 闪烁，记录时钟、分频和周期设置，整理一个最小示例。

这是入门练习建议，具体引脚和工程配置以你的开发板为准。遇到对应问题可以查STM32 常见问题。

你可以检查： 是否沿用已有基础，是否给出可执行的动作，是否把一般建议与课程文档正文区分清楚。

示例三：没有飞书读取工具，能否列完整采购表？

输入

我已经会 STM32，直接列出 ESP32S3 项目的完整器件、型号和数量。

当当前会话没有飞书正文和读取工具时，回答示例：

对应入口是ESP32S3 相关器件购买清单。当前技能包里有这个链接，但没有清单正文，我还不能确认课程具体使用的型号和数量。

你可以粘贴清单或上传文档，之后我会按“器件、准确型号、数量、用途、购买注意事项”整理采购表。

你可以检查： 是否提供准确入口，是否说明资料读取状态，是否避免把推测当成课程的完整 BOM。

怎样判断一次使用有没有帮助？

看回答是否明确了下一步行动、提供了对应资料入口，并正确处理已知背景和资料权限。代码、接线和器件选择仍要结合具体硬件验证。

已有技能后，可以复制任意输入试一次；还未安装时，先打开安装指南。
